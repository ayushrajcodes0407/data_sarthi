# Contributing to Data Sarthi

Thank you for your interest in improving Data Sarthi!

## How to Contribute
1. **Report Issues**: If you discover bugs or unexpected behavior in data quality scoring or chart rendering, open an issue detailing the dataset structure and steps to reproduce.
2. **Pull Requests**:
   - Keep pull requests focused and well-scoped.
   - Ensure all unit tests pass: `python -m unittest discover tests`.
   - Maintain the zero-external-dependency standard for the core engine.
3. **Coding Standards**:
   - Preserve clear documentation and docstrings.
   - Use clean, modern JavaScript for frontend components and standard library Python for backend modules.
